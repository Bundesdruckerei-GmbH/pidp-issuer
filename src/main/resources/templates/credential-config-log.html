Credential Configuration Changelog

ISO/IEC 18013-5 / mdoc

  • Initial creation from pid-mso-mdoc_2
  • Removes place_of_birth.no_place_info and expiry_date
  • Adds raw_eid_birth_date with partially unknown birthdate in namespace eu.europa.ec.eudi.pid.de.1
  • Updates birth_date to correspond to ISO 8601 (partially unknown birthdates get set to the last day of month / last month of year)
  • Introduces the German namespace eu.europa.ec.eudi.pid.de.1
  • Moves source_document_type to namespace eu.europa.ec.eudi.pid.de.1
  • Moves age_over_n (n=12, 14, 16, 18, 21, 65) to namespace eu.europa.ec.eudi.pid.de.1
  • Renames birth_place.locality to place_of_birth.locality in namespace eu.europa.ec.eudi.pid.1
  • Removes birth_place.country and birth_place.region
  • Adds place_of_birth.no_place_info in namespace eu.europa.ec.eudi.pid.de.1
  • Renames family_name_birth to birth_name and moves from namespace eu.europa.ec.eudi.pid.1 to eu.europa.ec.eudi.pid.de.1
  • Supports birth_date of the form YYYY-MM-DD where DD or both MM and DD can be zero
  • Adds also_known_as and academic_title in namespace eu.europa.ec.eudi.pid.de.1
  • Consistently contains all updated claims. Unset claims are represented as empty strings
  • Changes expiry_date from timestamp to type full-date
  • Removes issuance_date
  • Sets the claims signed, validFrom and validUntil to midnight in the Berlin time zone and represents them in the UTC time zone
  • Reorders claims in the credential metadata
  • This credential configuration is now stable. As a result, it has been renamed from pid-mso-mdoc_2-beta to pid-mso-mdoc_2.
  • This credential configuration is now deprecated. Use pid-mso-mdoc_2 instead.

SD-JWT VC

  • Initial creation from pid-sd-jwt_2
  • Removes place_of_birth.no_place_info and date_of_expiry
  • Adds raw_eid_birth_date with partially unknown birthdate
  • Updates birthdate to correspond to ISO 8601 (partially unknown birthdates get set to the last day of month / last month of year)
  • Adds place_of_birth.locality and place_of_birth.no_place_info
  • Removes place_of_birth.country and place_of_birth.region
  • Renames birth_family_name to birth_name
  • Supports birth_date of the form YYYY-MM-DD where DD or both MM and DD can be zero
  • Adds also_known_as and title
  • Consistently contains all updated claims. Unset claims are represented as empty strings
  • Adds date_of_expiry as string type with format YYYY-MM-DD
  • Adds nbf and removes iat claims
  • Sets the claims nbf and exp to midnight in the Berlin time zone and represents them as NumericDate type
  • Reorders claims in the credential metadata
  • Adds the parent claims address and age_equal_or_over in the credential metadata
  • This credential configuration is now stable. As a result, it has been renamed from pid-sd-jwt_2-beta to pid-sd-jwt_2.
  • This credential configuration is now deprecated. Use pid-sd-jwt_2 instead.

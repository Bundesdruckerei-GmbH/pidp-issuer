PID-Provider

The EUDI PID-Provider is a trustworthy service in the EUDI-Wallet ecosystem that verifies the identity of a user and issues a PID (person identification data).

This data is sourced by the german eID System.

The PID is issued in an EUDI-Wallet, where the user is able to provide/present it to relying parties to identify himself.

The relying party can verify the status of the PID against a Status-List provided by the PID-Provider.


Basic Functions of the PID-Provider

Verification and Authorization:
The eID-Functionality of german ID-Cards is used to verify the user, authorize him to issue a PID and therefore providing the necessary personal data on a high trust level (LoA High).
Issuance:
The PID-Provider issues (includes signing) the PID by using the verified eID-Data. The PID is provided to the users EUDI-Wallet that initiated the issuance.
Status-Information:
The PID-Provider provides the validity-status of a PID in a list. The relying party can fetch this information and verify the validity of the PID.
